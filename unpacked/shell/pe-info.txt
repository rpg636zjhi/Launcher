二、外壳是什么
  不是 launch4j，而是一个 .NET Framework 4.x 的 C# 程序：读取自身资源里的 jar 字节流，
  落盘成临时 launcher.jar，再找到可用的 Java 起进程。方法名散落在元数据里，可辨认的有：

    ReadEmbeddedJar     读出内嵌 jar
    ResolveJar          决定 jar 落到哪个路径
    FindJava            找 Java
    FindJavaInTree      按目录树找 Java
    Javaish / JavaMajor 判断是不是 Java、主版本号
    AutoFetchJava       找不到就自己下
    AddEnv              JAVA_HOME / PATH 处理
    AddFromWhere        调 `where java`
    AddRegistryJavaSoft 读 JavaSoft 注册表
    AddRegistryUninstall 读卸载表里的 JRE
    AddRoot
    get_IsReady
